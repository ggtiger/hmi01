01设计原则（玻璃工业风）

保持工业 HMI 的信息密度与操作确定性，用玻璃质感与光效提升视觉层级，避免花哨干扰读值。

深空底 + 玻璃层

  • 背景：深空黑蓝渐变 + 网格 + 双色光晕（青 / 紫）
  • 面板：半透明深色 + blur(18px) + 1px 高光描边 + 内高光
  • 层级通过"透明度 + 模糊 + 阴影"表达，而非粗边框

发光数据

  • 关键数值用青色发光（text-shadow），普通数值纯白
  • 状态灯为发光圆点（绿/琥珀/红）
  • 趋势曲线带渐变填充与光晕，光标虚线高亮

渐变强调

  • 主操作按钮：青→蓝渐变 + 发光投影
  • 危险操作：粉红→玫红渐变
  • 导航激活项：渐变胶囊；其余为玻璃按钮

工业约束

  • 一屏完整呈现数据（行高 34px，紧凑间距）
  • 空值 -- 灰化；报警用红色仅限关键状态
  • 主按钮 ≥ 48px，行内按钮 ≥ 34px（触屏）
  • 毛玻璃降级：不支持 blur 时回退半透明深色

09落地说明

毛玻璃工业风的实施要点与降级策略。

视觉令牌

  • 深空底 #060B12 + 网格 + 青/紫光晕
  • 玻璃面板 rgba(15,27,40,.55) + blur(18px) + 1px 高光描边
  • 强调渐变 #22D3EE → #3B82F6；危险 #FB7185 → #E11D48
  • 数值发光：关键值 text-shadow 青色光晕

实现要点

  • backdrop-filter 需父级有背景；Tauri WebView（WKWebView/WebView2）均支持
  • 降级：`@supports not (backdrop-filter: blur(1px))` 回退不透明深色
  • 发光与渐变集中在「面板头 / 按钮 / 数值 / 曲线」，避免大面积光效影响读值
  • 趋势图用 SVG 渐变填充 + feGaussianBlur 光晕

实施顺序

  • P1：全局令牌（深空底/光晕/玻璃类/渐变按钮/LED）
  • P2：顶栏、工具条、底部动作条与状态栏玻璃化
  • P3：命令监测页对齐 PPT、玻璃通讯面板
  • P4：踏板页补均匀力值、电机控制整合；帮助页
  • P5：趋势图发光化 + 触屏回归
