01设计原则（专业工控）

工控上位机的核心不是"现代感"，而是仪表化、可辨读、密集信息、确定性反馈。

仪表化视觉语言
  • 浅灰机柜底色 + 深蓝灰分组标题条（GroupBox）
  • 数值采用内嵌数字窗（凹陷边框 + 浅渐变），等宽字体
  • 按钮为立体按钮：上亮下暗 + 1px 外阴影，点击有内陷感
  • LED 状态灯（径向高光 + 发光），红色报警条
布局（对齐 PPT）
  • 顶部系统标题条：品牌 + 状态 + 页面导航 + 窗口按钮
  • 页面工具条：蓝牙模块联结、A/B 模块、无线/蓝牙设置
  • 左侧 GroupBox 数据面板（表格线 + 记录/清除）
  • 左下电机控制 GroupBox；右侧趋势控件；底部动作条 + 状态栏
信息密度与辨读
  • 行高 29px、紧凑 4–6px 间距，一屏容纳完整参数
  • 标签列固定宽 + 右对齐数值，小数点垂直对齐
  • 空值 --（灰化），不与 0 混淆
  • 状态色仅用于 LED / 报警 / 关键按钮
触屏与安全
  • 主按钮 44px 高；行内按钮 ≥ 29px，间距 ≥ 4px
  • 危险操作红色立体按钮 + 行内二次确认
  • 底部状态栏常驻：连接、事件、错误

09落地说明

与现有系统的映射及实施路径。

视觉换装要点
  • 全局令牌：机柜底 #D9E0E6、面板 #F3F6F8、标题条 #3F5162、边框 #9FB0BD
  • 新增组件类：GroupBox、数字窗、立体按钮、LED、趋势控件、状态栏
  • 数据行改为 29px 内嵌数字窗（等宽 13.5px）+ 行内小按钮
  • 主按钮深蓝、危险红色，均带立体高光
结构（对齐 PPT）
  • 顶部系统条（品牌 + 状态灯 + 导航 + 窗口按钮）
  • 页面工具条（模块联结、A/B 模块、无线/蓝牙设置）
  • 左侧 GroupBox 数据面板 + 左下电机控制
  • 右侧趋势控件；底部 44px 动作条 + 28px 状态栏
实施顺序
  • P1：全局 CSS 令牌 + 组件类（GroupBox/数字窗/立体按钮/LED/状态栏）
  • P2：顶栏、工具条、底部动作条统一换装
  • P3：命令监测页对齐 PPT（左说明 + 右通讯面板）
  • P4：踏板页补「均匀力值」、电机控制整合；帮助页浏览式布局
  • P5：触屏回归（44px 主按钮、行内 ≥ 29px、对比度）
