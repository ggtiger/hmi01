01设计原则

面向产线/实验室的工业测试上位机：信息密度高、操作可预测、状态一眼可读。

触屏优先 · 大目标

  • 主操作按钮高度 ≥ 44px，行内按钮 ≥ 32px
  • 数据块与按钮成组排列，减少误触
  • 开始/停止测试为整行大按钮，红色仅用于停止/危险操作

状态先行 · 一眼可读

  • 顶部固定状态栏：蓝牙模块连接数 / 测试状态 / 当前角度
  • 绿色 = 正常、琥珀 = 警告/未标定、红色 = 故障/停止
  • 底部 Info 栏常驻：最近事件与错误

数据即界面

  • 所有测量值用等宽数字 + 固定小数位，避免跳动
  • 空值统一显示 --，不与 0 混淆
  • 数据行右侧紧跟「记录 / 清除」等动作，降低操作跳转

渐进披露

  • 常用：数据面板 + 大图表；进阶：校准、手动调试、恢复出厂
  • 危险操作（恢复出厂、明文模式）用行内二次确认
  • 蓝牙多模块合并为一张「蓝牙采集模块」卡，按业务分组

09落地说明

本设计稿与现有实现的对应关系及建议实施顺序。

已具备（无需改动）

  • 转盘测试：双蓝牙模块、自由转角偏移基准、峰值/力值记录、双 Sheet Excel 导出
  • 设置：业务分组、AD 标定兜底、恢复出厂、行内二次确认
  • 设计系统：ui-data-box / ui-action-btn / 深墨蓝主色

建议新增 / 调整

  • 命令监测：左栏改为「模块状态 + 常用指令」卡（参考《软件UI》第 3 页），右侧通讯命令占满高度
  • 踏板测试：新增「均匀力值」字段；电机控制并入数据面板底部
  • 帮助页：改为帮助/上一页/下一页/主页 + 教学内容区（当前为关于页）
  • 导航：保持右对齐胶囊，补「帮助」入口（已有）

实施顺序建议

  • P1：命令监测页布局改版（信息栏 + 通讯面板）
  • P2：踏板页补充均匀力值、电机控制整合
  • P3：帮助页浏览式布局（先静态内容，后动画）
  • P4：统一回归（触屏尺寸、状态色、Info 栏）
