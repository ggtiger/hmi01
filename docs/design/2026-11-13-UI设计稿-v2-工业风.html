01设计原则（工业 HMI）

面向产线/实验室的固定工位设备：高对比、低认知负担、状态常显、操作可预测。

通栏结构，与 PPT 一致

  • 顶部 44px 通栏导航：品牌 + 状态灯 + 页面导航 + 窗口控制
  • 页面级工具条：蓝牙模块联结、A/B 模块等入口
  • 底部 动作条（48px 大按钮） + 通栏 Info 状态条

工业视觉语言

  • 深色底板 + 面板分层：#0B1117 / #121B24 / #0F1925
  • 1px 硬边框、2–3px 小圆角、内嵌深色数据格（表格式）
  • LED 状态灯（绿/琥珀/红）+ 等宽数字 + 固定小数位
  • 青色为操作强调，红色仅用于停止/危险操作

信息层级（参考 PPT 内容）

  • 踏板页字段：倾角 X/Y、垂直测距、起始/终末高度、高度差、实时/最大/均匀力值
  • 左下「电机控制部分」独立面板：调平电机 / 加载电机
  • 右侧「图表 A」大面板 + 底部 开始测试/记录/导出/踏板B

触屏与安全

  • 主操作 ≥ 44px 高；行内按钮 ≥ 30px，间距 ≥ 6px
  • 危险操作（恢复出厂/停止）红色描边 + 行内二次确认
  • 空值统一 --，不与 0 混淆

09落地说明

与现有系统的映射、视觉换装的实施路径。

结构映射（PPT → 系统）

  • PPT 顶部导航 → 通栏顶栏（命令监测/踏板测试/转盘测试/手动及状态检测/数据记录/设置/帮助）
  • PPT 模块按钮组 → 页面工具条（蓝牙模块联结、A/B 模块、无线/蓝牙设置）
  • PPT 左侧数据面板 → 现有数据面板（补齐字段：均匀力值）
  • PPT 左下电机控制 → 独立电机控制面板
  • PPT 右侧图表区 → 现有趋势图
  • PPT 底部动作条 + Info → 现有开始/记录/导出 + 全局 InfoBar

视觉换装

  • 主题：浅色 → 深色工业 HMI（#0B1117 底板，#121B24 面板）
  • 圆角：10–14px → 2–3px；阴影 → 1px 硬边框
  • 数据行：卡片式 → 表格式（标签列 + 右对齐等宽数值）
  • 强调色：深墨蓝 → 工业青 #2AA9C9；红色仅用于停止/危险

实施顺序（渐进式）

  • P1：全局主题变量与组件类（globals.css + 设计令牌）
  • P2：顶栏/工具条/底部动作条/Info 通栏统一
  • P3：命令监测页对齐 PPT 布局（左说明 + 右通讯面板）
  • P4：踏板页补均匀力值、电机控制整合；帮助页浏览式布局
  • P5：触屏回归（≥44px 控件、对比度、状态色）
