GUIDE

操作指引 先连板，再选侧，最后动

面向现场调试的五步流程与故障处理速查。

01

连接双板

在「连接」中分别连接 A/B 板；默认地址 192.168.8.88:10001 与 192.168.8.89:10001。板卡 LED 变绿并显示心跳时间，表示连接正常。

  • 已连接状态下 IP/端口锁定，需先断开再修改
  • A/B 独立心跳，15 秒无数据自动标记离线
02

选择目标板

点击左侧板卡或顶部 A/B 状态胶囊，切换目标板。所有动作按钮只作用于目标板，按钮上的 A/B 标识始终显示命令去向。

  • 调平、推出、回零、扫描等命令均按目标板路由
  • 切换目标板时同步该板 PEDAL SELECT
03

调平

点击「开始角度补偿」执行闭环调平；完成后日志显示 DEBUG LEVEL DONE comp=…，流程自动进入推出步骤。

  • 目标倾角 X = 0°，进入死区并确认后判定完成
  • 调平过程中手动操作电机会中止自动流程
04

推出

先设置推出距离（0–500 mm），再点击「启动加载」。未回原点时固件会自动回零，完成后自动推出。

  • 推出前请确认安全区域无人
  • STOP 只停止目标板流程
05

记录与导出

测试完成后在「记录」中查看调平、推杆与测量点数据；记录可展开查看明细，每条记录和全部记录均可导出。

  • 自动流程记录稳定点快照
  • 导出内容包含测量点明细与判定结果
!

故障恢复

急停后设备进入 FAULT，所有运动命令被拒绝。必须先执行「故障复位」RESET FAULT，再总使能继续操作。

  • 急停命令同时下发 A/B 两块板
  • 故障未复位时，开始测试会被拦截
