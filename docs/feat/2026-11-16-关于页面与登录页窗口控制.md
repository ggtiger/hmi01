# 关于页面与登录页窗口控制

> 日期：2026-11-16
> 分支：`feat/v6-system`

## 一、关于页面

此前 `/about` 实际是操作指引页，导航中也没有「关于」入口，用户无法找到应用版本、Server 版本、更新源等信息。

- 操作指引迁移到 `/help`，导航「帮助」指向 `/help`
- 新增 `/about` 关于页面：
  - 产品名称、图标、应用版本、Server 版本、固件版本、设备 ID
  - 更新源、七牛 CDN 状态
  - 产品特性、通信链路、数据存储
  - A/B 板在线状态、BLE 模块数量、协议、心跳、当前用户
  - 技术支持与操作指引入口
  - 「检查更新」按钮，复用现有更新检查与右下角通知
- 左侧导航新增始终可见的「关于」入口；`/about` 不参与功能权限路由重定向
- 版本号在浏览器模式下显示「浏览器模式」而不是 `v浏览器模式`

## 二、登录页拖动与窗口按钮

Windows 下运行时 `set_decorations(false)` 移除了原生标题栏，但登录页没有拖拽区域，也没有最小化/最大化/关闭按钮。

- 登录页根容器增加 `draggable-region` + `data-tauri-drag-region`
- 登录表单标记 `data-tauri-no-drag`，输入和按钮不触发拖动
- 登录页右上角复用 `WindowControls`
- 语言切换移到左下角，避开 Windows 窗口按钮和 macOS 红绿灯
- 顶部增加拖动提示

## 三、窗口控制按钮

- `WindowControls` 支持 `inline` 模式：
  - V6 顶栏使用 `inline`，参与布局，不再用 fixed 覆盖右侧的时钟/急停
  - 登录页使用默认 fixed 模式
- 按钮尺寸从 46×32 提升到 48×38，增加白色背景、边框、阴影、分隔线
- 图标颜色加深，hover/active 反馈增强；关闭按钮 hover 保持红色
- 顶栏在窄窗口隐藏时钟/参数/语言，保证 1024×768 下窗口按钮不被挤压或溢出
- 左下角用户入口增加「退出」文字，方便回到登录页

## 四、验证

- `npx tsc --noEmit` 通过
- `npm run build` 12 个路由通过
- 1280×860 与 1024×768 实际截图检查：
  - 关于页面无滚动条、导航高亮正常
  - 登录页拖动区域、窗口按钮、语言切换位置正常
  - 1024 宽度顶栏 `scrollWidth === clientWidth`，无横向溢出
