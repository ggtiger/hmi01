# 力值校正系数（默认 1）与软件校准

> 日期：2026-11-08
> 现象/背景：设置页「校准系数」此前显示为 weightG/adCode 的比值，不是业务意义上的校准系数；按业务（对齐 SSTS「校正系数」语义）校准系数默认应为 **1**，校准后更新为「标准值 ÷ 当前读数」，并用于修正所有力值显示
> 提交：本次提交

## 一、业务定义（对齐 SSTS control-force/torque 页面）

```ts
const correctionCoeff = parseFloat(correctionCoefficient) || 1     // 默认 1
const displayForce = scaleState.data.weightN * correctionCoeff      // 显示 = 读数 × 系数
const coefficient = standard / currentForce                          // 校准 = 标准值 ÷ 当前读数
```

- 系数为**软件校正系数**：默认 1.00000（不修正）
- 校准：放置已知砝码 → 输入重量(g) → 系统按 `standardN / 当前读数` 计算并保存系数
- 显示力值 = 传感器读数 × 系数，四个入口统一生效

## 二、实现要点

- `settings-store`：新增 `forceCoefficients: Record<channel, string>`（localStorage 持久化，默认空 → 回退 1）
  - `forceCoefficient(coefs, channel)` 工具：非法值回退 1
- 设置页模块行：显示「系数 1.00000」（默认）；校准按钮计算 `standardN/rawN`（读数 < 0.01 N 时禁用），系数按通道保存
- ForceModal：力值显示与系数显示应用同一系数；校准按钮同步改为软件系数计算（不再下发设备砝码标定命令）
- 转盘测试页：转向力实时值/趋势/最大记录均乘 TORQUE 系数
- 踏板测试页：A/B 侧实时力值、最大力值乘对应通道系数
- 校准说明改为三步：清零（设备零点命令）/ 校准（软件系数）/ 系数（读数 × 系数）

## 三、验证

- `npx tsc --noEmit` 零错误；`next build` 11/11
- 预期行为：未校准显示系数 1.00000；放砝码点击校准后系数更新、实时力值等于砝码标准重量；刷新/重启后系数保留
