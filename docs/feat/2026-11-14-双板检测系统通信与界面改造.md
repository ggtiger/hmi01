# 双板检测系统通信与界面改造

> 日期：2026-11-14
> 类型：功能新增 / 架构调整
> 提交：本次提交

## 一、双板通信架构

- 新增 `BoardMap`，A/B 两块下位机各自拥有独立 TCP、加密上下文、心跳（5s PING / 15s 超时）、遥测与日志
- 前端 `useDevice` 改为同时维护 A/B 两份 `DeviceState`，并合并为现有页面使用的单一遥测视图
- Tauri 命令按板侧路由：
  - 踏板命令 → 对应板
  - 电机命令 → 按轴名路由（A/PUSH_A → A 板，B/PUSH_B → B 板）
  - 急停、总使能/释放/全轴停止 → 两块板同时下发
- 事件与日志携带 `board` 字段，控制台按 `[A]/[B]` 展示

## 二、协议补充

- 新增命令：`RESET FAULT`、`GET PARAMS`、`SCAN`、`SET PUSH_FEED`、`SET LEVEL_SPEED`、`SET LEVEL_TOL`、`SET MSH_ZERO_CLEAR`、`SET SIDE`、`SET LEVEL_METHOD`
- 兼容新固件 `HELLO OK <id>`（无固件版本）与裸 `INFO`，旧固件回退 `INFO GET`
- 遥测新增：`side`、`push_a/b_raw`、`push_a/b_st`、`steer_free`
- DEBUG 事件新增：LEVEL START、HOME START/DONE、PUSH HOMING/STARTED/DONE
- 新增 PARAMS 解析与 `last_pong` 心跳时间
- 踏板遥测 `pedal_a/b` 按新协议视为 mm（脉冲原值使用 `push_*_raw`）

## 三、页面

- 命令监测：A/B 双板独立 IP/端口连接、目标板选择、通信日志带板号、新增 RESET FAULT / GET PARAMS / SCAN 快捷命令
- 手动及状态检测：目标板选择、角度补偿、推出控制、推杆回零、MSH 设零、Modbus 扫描、STOP、故障复位、全字段遥测
- 踏板测试：按侧别校验 A/B 板可用性，故障态拦截与复位
- 设置：参数收敛为 3 项（补正模式 / 推杆脉冲当量 / 推杆速度）；移除目标板操作面板与多余参数
- 状态栏与调试页显示 A/B 独立心跳时间

## 四、双语

- 新增 `lib/i18n` 中英词典与语言切换，覆盖顶栏、页面、弹窗、导出表头等

## 五、设计原型
