# 按《软件UI》PPT 重构页面布局 + 浅色毛玻璃主题

> 日期：2026-11-13
> 现象/背景：此前页面内容与《软件UI.pptx》布局稿不匹配（命令监测页缺失左说明/右通讯布局、踏板页字段不同、帮助页为关于页）；视觉也需按用户要求改为浅色毛玻璃工业风
> 提交：本次提交

## 一、页面重构（对齐 PPT 四页）

**导航（TopAppBar）**
- 顺序对齐 PPT：踏板测试 / 转盘测试 / 命令监测 / 手动及状态检测 / 数据记录 / 设置 / 帮助
- 新增「语言」下拉（简体中文；English 即将支持），保留窗口控制
- 顶栏改为白色毛玻璃

**命令监测页（PPT 第 3 页）**
- 工具条：命令监测模块状态 + 「无线设置」（聚焦连接参数）+「蓝牙设置」（ForceModal 扫描/连接）
- 左栏（340px）：系统测试命令说明 + 常用命令一键下发 + 5 个蓝牙模块状态 + 无线连接参数（IP/端口/连接/断开）
- 右栏：上下位机通讯命令大面板（DebugConsole，bare 模式嵌入玻璃面板）

**踏板测试页（PPT 第 2 页）**
- 工具条：蓝牙模块联结 / A 模块 / B 模块 / WiFi 状态 / 流程阶段 / 急停
- 左侧数据面板：倾角 X/Y、垂直测距（清零）、起始/终末高度、高度差、实时力值（记录）、最大力值、均匀力值、电机控制部分（调平/加载电机）
- **字段修正**：移除 PPT 中没有的「水平测距、起始/终末进深、进深差、进程力值」；新增「均匀力值」（最近 30 个力值采样的滑动平均，每 5 帧更新）
- 右侧：图表 A（趋势/事件 Tab + 记录点表）
- 底部动作条：开始测试 / 记录 / 导出 / 清除 / 踏板 B

**帮助页（PPT 第 4 页，原 /about）**
- 顶部按钮：帮助 / 上一页 / 下一页 / 主页（返回应用主页）
- 6 个内容页：转盘测试指引、踏板测试指引、蓝牙模块联结、力值校准、网络设置与恢复出厂、版本与设备信息（含检查更新）

## 二、浅色毛玻璃主题

`app/globals.css` 新增设计令牌与组件类：
- `.app-bg`：浅灰蓝底 + 柔和青/紫光斑 + 网格
- `.glass-panel` / `.glass-panel-header`：白色半透明 + blur(18px) + 白色高光描边 + 柔和蓝灰投影
- `.glass-row` / `.glass-btn` / `.glass-action` / `.led`：玻璃数据行、按钮、动作按钮、发光状态灯
- 全局旧类换装：`.industrial-card`、`.ui-data-box`、`.ui-action-btn`（含 primary/danger）、`.ui-info-bar` 全部改为浅色玻璃风格，老页面（转盘/设置/电机调试/记录）自动统一
- `DebugConsole`：新增 `bare` 模式（嵌入玻璃面板不套卡片），按钮改青蓝渐变
- layout body 使用 `app-bg`；InfoBar footer 透明化
