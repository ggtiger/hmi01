# 测试台工作台 UI 改版（参考 PPT 设计稿布局）

> 日期：2026-09-20
> 现象/背景：用户提供产品 UI 设计稿（.tmp/*.pptx，7 页：迎宾页/踏板测试 A·B/转盘测试/设置/命令监测/帮助），要求按设计稿优化整个 UI；配色保持现有品牌深色主题（primary #041627），只参考布局结构
> 提交：本次提交

## 一、背景与目标

设计稿分析（LibreOffice 转 PDF → 图片逐页确认）：
- **统一布局语言**：顶部导航（右对齐）+ 左侧数据/操作面板 + 右侧大图表区 + 底部操作栏 + 每页底部 Info 状态栏
- **踏板测试页（slide2/3）为单侧工作视图**：顶部连接/侧选/加载行 → 左侧数据面板（倾角、垂直/水平测距、起始/终末高度、高度差、起始/终末进深、进深差、实时/最大/进程力值，各带「记录/清除」按钮，底部调平电机/加载电机控制行）→ 右侧大图表区 → 底部「开始测试/记录/导出/踏板B 切侧」
- 配色：设计稿蓝色仅为占位（theme accent1 #4472C4，156 处引用），用户明确要求沿用现有品牌深色主题

## 二、方案设计

字段映射（设计稿 → Xdesin 协议遥测，协议没有的显示 `--`）：

| 设计稿字段 | 协议映射 |
|---|---|
| 倾角 X/Y | `pedal_<side>_tilt_x/y` |
| 垂直测距 | `laser_<side>`（激光测距 mm） |
| 水平测距 | 协议无 → `--`（预留） |
| 起始/终末高度 | 记录点快照（laser 值，起始手动记录、终末实时跟随） |
| 高度差/进深差 | 本地计算（终末-起始） |
| 起始/终末进深 | 推杆位置（`pedal_<side>` 脉冲 ÷ 脉冲当量） |
| 实时/最大/进程力值 | 协议无力值遥测 → `--`（SETLOAD 仅下发） |
| 调平电机 设置角度/启动/调平补偿 | `MOTOR <side> MOVE` / `PEDAL <side> LEVEL` |
| 加载电机 设置/启动加载/+/- | `PEDAL SET PUSH_DIST` / `PUSH START` / `MOTOR PUSH_<side> MOVE ±1` |
| 激光安装倾角 X/Y | 公用 `tilt_x/tilt_y` |

## 三、实现要点

- **设计系统**（globals.css）：`ui-data-box`（浅灰数据块）、`ui-action-btn`（深色圆角按钮 + ghost/danger 变体）、`ui-input`、`ui-info-bar`，全部基于现有 token
- **踏板测试页重构**（app/pedal-test/page.tsx）：单侧工作视图；终末高度/进深随遥测实时更新（起始值手动「记录」快照）；右侧图表区 Tab 切换（趋势/事件时间线）；记录点表格折叠在图表下方
- **PedalDataPanel**（新组件）：数据行 + MiniBtn，「记录」按钮把当前遥测值快照为该字段并存入记录点列表
- **主页**：未连接 → 迎宾视图（slide 1：Logo + 大标题 + 信息条 + 连接卡片）；已连接 → 命令监测视图（slide 6：左栏连接/遥测/急停 + 右栏上下位机通讯命令控制台）
- **InfoBar**（新全局组件）：layout 底部状态栏（连接状态 | 设备状态 | 最近事件/错误，ABORT 红色警示）
- **TopAppBar**：导航改为右对齐胶囊（命令监测/踏板测试/电机调试/数据记录/设置/帮助），贴近设计稿
- 电机调试页按钮统一为 ui-action-btn；DebugConsole 改为 flex 填充高度

## 五、教训与关联

- PPT 解包分析：slide XML 无显式颜色时看 theme accent 引用（本稿 156 处 accent1=#4472C4 为占位色）
- 设计稿字段不应机械照搬——按协议能力映射，缺失字段显示 `--` 并保持布局占位（水平测距、力值），便于后续协议扩展时直接接入
