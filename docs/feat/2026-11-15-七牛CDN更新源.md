# 七牛 CDN 更新源

> 日期：2026-11-15
> 分支：`feat/v6-system`

## 目标

GitHub Release 资产在国内网络可能无法访问。发布流程增加七牛云 CDN：

- 更新清单：`https://o09u11p5v.qnssl.com/hmi/latest.json`
- 全量包 / 安装包 / 增量包：`https://o09u11p5v.qnssl.com/hmi/releases/<version>/...`

## 实现

- 新增 `scripts/sync-cdn.mjs`
  - 从 GitHub Release 下载当前发布资产
  - 通过七牛 S3 兼容接口上传
  - 将 `latest.json` 中的 Windows 安装包、server 全量包、server 增量包 URL 全部改写为 CDN 地址
  - 把改写后的 `latest.json` 回写 GitHub Release，作为兼容回退清单
- `release.yml` / `server-release.yml` 增加 CDN 同步步骤
- `configure-release.mjs` 在存在 `UPDATE_CDN_BASE_URL` 时把 Tauri updater endpoint 指向 CDN
- `lib/config.ts` 默认 CDN 更新源改为七牛 CDN，可用 `NEXT_PUBLIC_UPDATE_CDN_URL` 覆盖

## 七牛配置

- 业务 bucket：`gjapp`
- 七牛 S3 源 bucket：`7xjehb`
- CDN 域名：`https://o09u11p5v.qnssl.com/hmi`
- GitHub Secrets：
  - `QINIU_ACCESS_KEY`
  - `QINIU_SECRET_KEY`
  - `QINIU_BUCKET=gjapp`
  - `QINIU_S3_BUCKET=7xjehb`
  - `QINIU_CDN_BASE=https://o09u11p5v.qnssl.com/hmi`

说明：当前 AK/SK 是七牛 S3 兼容接口可用的密钥；七牛控制台中的 gjapp 对应 S3 源 bucket `7xjehb`。后续若换成原生 Kodo 密钥，需要再调整上传实现。

## 版本迁移

已安装的 `v0.1.0` 客户端内置的是 GitHub 更新地址，无法远程改变 endpoint。需要发布一个使用 CDN endpoint 的新版本（`v0.1.1`）；用户首次手动安装该版本后，后续全量和增量更新走 CDN。
