# 转盘测试模块实现（STEER）

> 日期：2026-09-20
> 现象/背景：PPT 设计稿包含「转盘测试」页（slide 4）且导航栏有对应入口，但初版未实现——协议 §2.9 STEER 命令标注"不使用"、遥测 steer_x/y 标注"预留"、STEER_X/Y 电机轴标注"保留"。用户确认需要该模块后按设计稿补齐
> 提交：本次提交

## 一、背景与目标

设计稿 slide 4 布局：顶部连接/无线状态/倾角行 → 左侧数据面板（方向盘 X/Y、自由转角、顺时针/逆时针、实时/最大/进程力值）→ 右侧大图表区 → 底部开始测试/记录/导出。

协议侧已有的定义可直接使用：
- §2.9：`STEER START` / `STEER STOP`（应答 `OK STEER`，START 后设备状态 → `STEER_RUN`，STOP 回 `IDLE`；错误 `ERR STEER E_SYNTAX`）
- §3.2 遥测：`steer_x`/`steer_y`（方向盘 X/Y 命令位置，°）

## 二、实现要点

**Rust 协议层**：
- `protocol.rs`：`Command::SteerStart/SteerStop` 变体 + `to_frame()` + 命令头 `STEER` + 帧断言单测
- `commands.rs`：`steer_start`/`steer_stop`（6s 超时，对齐流程类命令）；`lib.rs` 注册（总命令数 31→33）

**mock 模拟器**：
- `handleSteer` 分发：START → `devState='STEER_RUN'`，STOP → `'IDLE'`，非法参数回 `ERR STEER E_SYNTAX`
- 遥测：STEER_RUN 时 `steer_x = 30·sin(t/3)`、`steer_y = 20·cos(t/4)` 缓速正弦扫描，停止时归零

**前端**：
- `device-service.ts`/`use-device.ts`：steerStart/steerStop actions
- `app/steering-test/page.tsx`（slide 4 布局 + 工作台设计系统）：
  - 数据面板：方向盘 X/Y（遥测实时值）、自由转角（方向反转点幅值自动捕获）、顺时针/逆时针峰值（运行中自动跟踪最大值/最小值）、力值显示 `--`（协议未提供）
  - 趋势图：steer_x/steer_y 双曲线（200ms 采样门控）
  - 记录点：本地记录 + CSV 导出；开始测试 = STEER START/STOP 切换
- TopAppBar 导航加「转盘测试」（`rotate_right` 图标）

## 三、验证

- `cargo test` 14/14（含 STEER 帧断言）
- mock E2E 4/4：`STEER START` → `OK STEER` + `state=STEER_RUN` + steer_x/y 遥测变化；`STEER STOP` → 回 IDLE
- `npx tsc` 零错误；`next build` 11/11 页面通过；Playwright 截图布局与设计稿一致
