# 设置页按业务语义重构（分组 + 触屏友好）

> 日期：2026-11-08
> 现象/背景：设置页蓝牙模块列表平铺 5 个通道，开关通道误显「清零/砝码/校准」操作；力值行显示无意义的「系数」；顶部「未连接设备」横幅误导（蓝牙设置不依赖 WiFi）；整体布局偏窄、按钮偏小
> 提交：本次提交

## 一、业务语义梳理

| 分组 | 模块 | 数值 | 允许操作 |
|---|---|---|---|
| 转盘测试 | 倾角模块（STEER） | 倾角 X / Y | 无（Modbus RTU 轮询） |
| 转盘测试 | 转向力（TORQUE） | 实时 / 最大力值 N | 清零（零点校准）、砝码校准 |
| 踏板测试 | 模块 A / B | 实时 / 最大力值 N | 清零、砝码校准 |
| 辅助设备 | 二路开关（SWITCH） | 第 1/2 路开/关 | 无（继电器状态） |

修正的问题：
- 二路开关行原显示「清零 / 砝码 g / 校准」（条件只排除了 STEER，漏排 SWITCH）
- 力值行「系数」是 weightN/weightG 的恒等换算（恒为 1），无业务意义 → 改为「最大力值」
- 设备名 `truncate` 导致 "WEIGH..." 无法辨认 → 保留完整名称（title 提示）

## 二、页面结构

1. **状态概览条**：蓝牙模块 x/5 已连接 | WiFi 设备 已连接/未连接，注明「蓝牙采集不依赖 WiFi 连接」
2. **蓝牙采集模块**卡片：按「转盘测试 / 踏板测试 / 辅助设备」三个业务分区分组，每组小标题 + 说明；模块行含状态点、名称、完整设备名、业务数值块（ui-data-box）、按类型显示操作
3. **设备参数（SET）**：行式布局（名称 + 说明 / 输入 / 单位 / 应用按钮），未连接 WiFi 时行内提示「修改将在连接后生效」
4. **通信调试**：加密/明文模式说明 + 二次确认切换
5. **网络配置（NET）**：当前配置展示块、三字段修改、恢复默认（危险操作独立分区）
