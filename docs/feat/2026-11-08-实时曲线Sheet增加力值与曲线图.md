# 实时曲线 Sheet 增加实时力值与顶部曲线图

> 日期：2026-11-08
> 现象/背景：导出 Excel 的「实时曲线」Sheet 缺少实时力值列，且用户希望数据上方直接展示一张曲线图
> 提交：本次提交

## 一、实现要点

**趋势数据补力值**（`app/steering-test/page.tsx`）：
- `TrendPoint` 增加 `torque` 字段；趋势推送 effect 依赖加入 `torqueLive`
- 采样门控保持 200ms（角度与力值同一时间轴）
- 时间标签改为 `时:分:秒`（HH:MM:SS），UI 趋势图与导出 Excel 的「实时曲线」Sheet 一致

**曲线图渲染**（`lib/export-excel.ts`）：
- SheetJS 社区版不支持图表，改用 **ExcelJS**（替代 `xlsx` 依赖）
- 新增 `renderLineChartPng(labels, series)`：浏览器 Canvas 手绘多曲线图（1200×420 PNG）
  - 角度系列共用左轴缩放，力值（`separateScale`）独立右轴缩放
  - 网格、左右刻度、首/中/尾时间标签、标题 + 图例
- `SheetSpec.chartImage`：Sheet 顶部插入图片（锚定 A1），数据自动下移到图片下方（24 行偏移），表头加粗、列宽统一
- 保存路径不变：Tauri 系统保存对话框 + `save_file_content`；浏览器 Blob 下载

**Sheet 结构**：
1. 记录值：序号 / 时间 / 记录项 / 值 / 单位
2. 实时曲线：**顶部曲线图**（倾角 X / 倾角 Y / 自由转角 / 实时力值 四条线）+ 下方数据表（时间 / 倾角 X / 倾角 Y / 自由转角 / **实时力值**）

## 三、依赖变更
