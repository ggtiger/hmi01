# 基于 V6 原型实现双板检测系统界面

> 日期：2026-11-14
> 分支：`feat/v6-system`
> 依据：`docs/design/2026-11-14-双板调试台原型-v6.html`

## 一、应用外壳

- 新增 `V6Shell`：顶栏（品牌、A/B 板状态与心跳、BLE 数量、连接、参数、语言、时钟、急停）+ 左侧导航 + 底部状态栏
- 导航按权限动态显示：调试台 / 踏板 / 转盘 / 记录 / 设置 / 帮助
- 无权限路由自动重定向到第一个有权限页面
- 保留 `ForceModal`（现有蓝牙模块管理）作为蓝牙设置入口

## 二、启动、登录与权限

- WebView 内启动加载动画（900ms）
- 登录页：用户名 / 密码、错误提示、中英切换
- 本地用户表（`lib/store/user-store.ts`，localStorage 持久化）：
  - admin / admin123（管理员，全部功能）
  - operator / 123456（操作员）
  - debug / debug123（调试员）
- 设置页用户管理：
  - 新增 / 编辑 / 删除用户
  - 用户名、密码、角色
  - 可用功能权限（踏板/转盘/调试/记录/设置/帮助）
  - 修改当前用户立即生效
- 左下角用户头像退出登录

## 三、连接向导

- 登录后自动打开，可跳过，稍后从顶部「连接」重新打开
- A/B 板独立 IP/端口、连接/断开、心跳显示
- 蓝牙模块状态与「蓝牙模块联结 / 详细设置」入口
- 开始踏板测试校验对应板 + 对应力值模块；开始转盘测试校验倾角 + 转向力模块

## 四、页面

- 踏板测试：测量表（含逐项记录/清除）、电机控制、图表、图表下本次记录、Info、底部动作；开始前连接拦截
- 转盘测试：倾角/自由转角/顺逆峰值/力值、图表、记录列表、Excel 导出
- 数据记录：卡片列表、展开明细、逐条导出、全部导出、删除
- 帮助：左右箭头、圆点、页码、键盘左右、触摸滑动
- 设置：三项参数（补正模式 / 推杆脉冲当量 / 推杆速度）+ 用户管理
- 调试台：目标板、手动单步、全字段状态、故障复位

## 五、说明

- 用户密码本地明文保存，后续可替换为系统凭据或加密存储
- 蓝牙模块管理沿用现有 `ForceModal`，未重绘
- 1024×768 触屏版 `v7` 尚未移植到应用代码
