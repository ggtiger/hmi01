# 调试台、踏板、转盘 UI 优化

> 日期：2026-11-15
> 分支：`feat/v6-system`

## 一、调试台

- 重排为「设备总览 → 测试控制 / 实时状态 → 轴手动控制」
- 目标板/在线状态/设备号/固件/心跳统一为顶部状态区
- 测试控制按调平、推杆、诊断分三组
- 遥测从长表格改为分层卡片：
  - 设备状态使用深色状态卡（IDLE/运行/FAULT 不同配色）
  - 传感器 OK/NG 使用绿/红背景
  - 主指标放大，推杆与方向盘分组显示
- 轴控制改为固定工作区，选择轴自动同步目标板
- 使用固定 1280×740 设计画布 + ResizeObserver 等比缩放：
  - 不出现页面滚动条
  - 不裁切卡片
  - 上下/左右留白由画布动态铺满
- 错误提示改为浮层，不再撑高页面

## 二、踏板测试

- 测量行改为弹性行高，完整显示且不出现内部滚动条
- 电机控制固定在左侧面板底部，不随数据区滚动被顶走
- 调平电机/加载电机/安全控制三行统一标签列、输入框和按钮
- 输入框增加单位、白色背景、深色边框
- 按钮使用浅蓝灰实底、边框、阴影；主操作/危险操作保留彩色
- 各行按可用高度共同分配，避免上方区域被单独拉高

## 三、转盘测试

- 数据面板拆分为「姿态 / 峰值 / 力值」三个分组卡片
- 数据行弹性填充，无滚动条
- 记录规则固定在底部
- 记录按钮仅在有效值时可用；无效值灰显
- `addRecord` 增加 null/NaN 兜底，不会写入空记录
- 清零/记录/清除逻辑与上一版保持一致
- Excel 导出逻辑与格式保持不变

## 四、按钮 hover

修复 `.glass-btn` / `.ui-action-btn` / `.glass-action` 彩色按钮 hover 变白导致白字不可见的问题：

- primary hover 保持青蓝渐变
- danger hover 保持红色渐变
- 文字始终为白色
- 提升阴影反馈

## 五、验证

- `npm run build` 通过
- `npx tsc --noEmit` 通过
- `cargo test` 32 passed
- 1280×860、1024×768 实际截图检查无滚动条/无遮挡
