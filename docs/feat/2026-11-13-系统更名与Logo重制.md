## 二、Logo 设计

`src-tauri/icons/icon-source.svg`（矢量源，1024×1024）：
- 深蓝青渐变圆角底板（#081A29 → #0E7490）
- 顶部青色渐变检测波形（发光，#22D3EE → #3B82F6）
- 中央方向盘（外圈 + 中心 + 三辐条，浅青白描边）
- 底部仪表刻度线 + 低调网格（仪表感）

生成流程：
```bash
rsvg-convert -w 1024 -h 1024 src-tauri/icons/icon-source.svg -o src-tauri/icons/icon-source.png
npx tauri icon src-tauri/icons/icon-source.png   # 生成全平台图标
cp src-tauri/icons/icon-source.png public/icon.png
```
- 生成 32/64/128/128@2x/256/512 PNG、icon.icns、icon.ico、Windows Store Square 系列
- 删除 android/、ios/ 目录（本项目仅桌面双平台）
- splash 通过自定义协议返回 `icons/icon.png`，自动使用新图标
