# 踏板测试台上位机骨架初始化（XdesinHMI）

> 日期：2026-09-07
> 现象/背景：项目仅有 `docs/1.md`（Xdesin 上下位通信协议），需从零搭建可运行的上位机：Rust 通信层、全部页面、mock 设备联调、自动升级框架
> 提交：61fc534（骨架）、f910976（server 产物不入库修正）

## 一、背景与目标

Xdesin 踏板总成测试台：上位机经 WiFi TCP（`192.168.4.1:10001`，上位机为 Client）连接 ESP32-S3 下位机，AES-128-CTR + HMAC-MD5 加密封装，对 A/B 双侧踏板执行自动调平/推出测试，10Hz 遥测，记录存本地 SQLite。

已确认决策：沿用 SSTS（已验证的 Next.js 15 + Tauri 2 工业上位机）的 sidecar 架构；双平台 macOS + Windows。

## 二、方案设计

复刻 SSTS 分层，替换通信域：

```
hmi01/
├── app/                    # 6 页面：主页/踏板测试/电机调试/记录/设置/关于
├── components/ui/          # SSTS 基础件复刻 + 8 个新域组件（EstopButton/PedalSideCard/TiltIndicator…）
├── lib/comm/               # TS 三层：types / device-service / use-device
├── lib/store/              # zustand：app/pedal/motor/settings/updater
├── lib/db/test-records.ts  # SQLite 宽表 + JSON 测量数据
├── scripts/mock-device-server.js  # 纯 Node 协议模拟器（与 Rust crypto 对拍）
└── src-tauri/src/comm/     # crypto/protocol/connection/heartbeat/state/commands
```

关键选型：
- **crypto 用 tokio Mutex 跨 await 持锁**：tx_nonce 分配与 socket 写同临界区，保证 nonce 顺序 = 线序（心跳与命令并发时不触发对端重放丢弃）
- **pending 表**：`HashMap<命令头, oneshot::Sender>` 匹配应答（协议是命令头匹配而非 seq），超时清理防串包；`cmd_mutex` 串行化（协议 §2.1）
- **遥测两级节流**：emit 20Hz（UI）+ 日志采样 1Hz（防刷屏）
- **明文切换编排**：PLAIN ON 收到 OK（最后一帧加密）后才翻 plain_mode；PLAIN OFF 明文发出后立即翻回

## 三、实现要点

- `src-tauri/src/comm/crypto.rs`：IV = 14×0x00 + nonce BE，`Ctr128BE<Aes128>`；HMAC 常时比较；重放保护含回绕放行（last>0xF000 && cur<0x0FFF）
- `src-tauri/src/comm/state.rs`：CommManager 连接编排（TCP→复位加密→HELLO→INFO→SET REPORT→心跳）；15s 无数据断开 = 心跳超时
- `scripts/mock-device-server.js`：状态机 IDLE/AF_LEVELING/PUSHING/FAULT，LEVELED/STABLE/ABORT 事件序列、E_RANGE/E_SYNTAX/E_AXIS 典型分支
- 协议核对修复 3 处：`LASER_X/TILT_X` 预留位误写 angleComp、回零中打断缺 `PUSH_STOPPED`、趋势换算未用可配置脉冲当量

## 四、验证

- `cargo test` 14/14（含 Rust↔Node 跨语言加密对拍向量 `test_node_cross_vectors`）
- mock E2E 4/4：握手→遥测→LEVELED→ERR 分支→ESTOP→ABORT 链
- `next build` 7 页面通过；`tauri build` 产出 .app + dmg(20M)；生产 .app 冒烟：sidecar server 启动、`/api/health` OK
- 性能优化：actions `useMemo` 稳定引用 + DebugConsole/EventTimeline memo 化 + 趋势 5Hz 采样（recharts 开销 -75%）

## 五、教训与关联

1. **tauri 2.10.3 + tauri-runtime-wry 2.11.4 编译不兼容**（E0308），必须锁 SSTS 的 Cargo.lock 组合（tauri 2.10.0 + runtime-wry 2.10.0 + wry 0.54.4）
2. **bundle.resources 在 dev 也做存在性校验**：`src-tauri/server/` 需占位文件，且不能只有隐藏文件（`**/*` glob 不匹配 dotfile）；`tauri:build` 会把该目录重写为真实 bundle，故整目录不入库，dev 占位由 `scripts/ensure-placeholders.js`（beforeDevCommand）生成
3. **dev 会话运行期间禁止跑 `npm run build`**：两者共用 `.next`，build 清空重建会导致 dev server 500
4. 待办：minisign 密钥对重新生成、升级 endpoints 配置（当前为占位，冷启动会等 GitHub curl 超时 ~15s）
