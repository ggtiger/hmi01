# 转盘测试峰值「记录」未写入历史记录表

> 日期：2026-11-08
> 现象：点「顺时针峰值」「逆时针峰值」行的「记录」按钮，峰值行有值，但下方历史记录表只有「最大力值」条目，没有峰值记录
> 提交：f5fdead

## 一、问题定位

`app/steering-test/page.tsx` 的 `recordCwPeak` / `recordCcwPeak` 只调用了 `setCwAngle` / `setCcwAngle`（更新峰值显示），**漏了 `addRecord(...)`**（写历史记录表）。最大力值的「记录」按钮调用 `addRecord` 正常，所以对比明显。

## 二、修复

两个峰值记录函数补充写入：

```ts
const recordCwPeak = () => {
  if (freeAngle === null || freeAngle <= 0.001) return
  setCwAngle(freeAngle)
  addRecord('顺时针峰值', freeAngle)   // ← 新增
}
```

逆时针同理。记录项的值为记录时刻的自由转角（顺时针为正、逆时针为负）。

## 三、验证

- `npx tsc --noEmit` 零错误；`next build` 11/11
- 行为：记录后峰值行与历史表同时出现该值

## 四、教训

同一按钮有多个 UI 副作用时容易漏（显示 + 历史表）；参考踏板页 `recordField` 的实现同时做快照与 `addRecord`，后续新记录按钮对齐该模式。
