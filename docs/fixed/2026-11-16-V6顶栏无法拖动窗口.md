# V6 顶栏无法拖动窗口

> 日期：2026-11-16
> 分支：`feat/system` / `main`

## 现象

V6 应用外壳顶栏没有拖拽区域，Windows 下无法通过顶栏移动窗口。

## 原因

旧的 `TopAppBar` 带有 `draggable-region` 和 `data-tauri-drag-region`，但 V6 改版后导航和顶栏迁移到 `V6Shell`，这两个拖动标记没有同步过去。

## 修复

- `V6Shell` header 增加 `draggable-region` 和 `data-tauri-drag-region`
- 顶栏中部增加空白拖拽区域和拖动提示图标
- 交互元素（button/a/input/select/textarea）统一设置为 no-drag
- 中间空白区域保留 drag，避免点击按钮时触发窗口拖动

## 发布

该修改只涉及 Next.js server 前端，采用 `server-v0.1.2` 增量热更新，不重新构建 Windows 安装包。
