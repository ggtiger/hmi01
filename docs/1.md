# Xdesin 上下位通信消息参考

字符集：UTF-8；行结束符：`\n`；小数点：`.`；不可用数值：`nan`；命令大小写不敏感。

---

## 1. 链路与传输

### 1.1 链路参数

| 项 | 值 |
|----|----|
| 物理层 | WiFi 2.4GHz |
| 默认 SSID / 密码 | `XDESIN` / `88888888` |
| 服务地址 | `192.168.4.1:10001`（TCP） |
| 角色 | 下位机 = TCP Server；上位机 = TCP Client |
| 设备 ID | `xdesin-s3-001` |
| 固件版本 | `1.0.0`（随固件更新） |
| 心跳超时 | 双向无数据 15s 后下位机主动断开 |
| 建议心跳节奏 | 上位每 5s 发 `PING` |

### 1.2 传输封装

TCP 链路上每条消息 = 一行密文 + `\n`：

```
base64( nonce[2B] || ciphertext[NB] || hmac[16B] ) \n
```

- **PSK**：`'Xdesin0123456789'`（16 字节 UTF-8，两端写死）
- **对称加密**：AES-128-CTR，key = PSK
- **CTR IV**：16 字节，前 14 字节为 0x00，末 2 字节为 nonce（大端）
- **完整性**：HMAC-MD5(key = PSK, message = nonce ‖ ciphertext)，取完整 16 字节
- **nonce**：uint16 发送计数器，每包 +1，0xFFFF 后回绕到 0；每次新建 TCP 连接双方都重置为 0
- **重放保护**：接收端记录上次成功解包的 nonce，本次 ≤ 上次值则丢弃（回绕放行：上次 > 0xF000 且本次 < 0x0FFF）

### 1.3 明文调试模式（可选）

调试场景下可切换为明文行传输，跳过 1.2 的加密封装：

```
→ DEBUG PLAIN ON            ← 加密帧
← OK DEBUG PLAIN ON         ← 最后一帧加密，之后双方收发均为明文行
→ HELLO my-tool             ← 明文
← HELLO OK xdesin-s3-001 1.0.0
← TELEMETRY t=100 ...       ← 明文遥测
→ DEBUG PLAIN OFF           ← 明文发出后链路立即切回加密
← OK DEBUG PLAIN OFF        ← 加密帧
```

**明文入口**：加密模式下直接发送明文行 `DEBUG PLAIN ON`（下位机解密失败后按明文白名单放行这一条），无需实现加密即可切入明文会话。其他明文命令在加密模式下一律忽略。

**明文模式下的双模式收包**：下位机在明文模式下，仅对形似加密帧的收包行（长度≥24 且全为 base64 字符，即解码≥18 字节）尝试按加密帧解析，校验通过则按加密命令执行，否则一律按明文命令处理——用于兼容切换瞬间在途的加密行（如上位心跳 PING）。上位机在明文模式下心跳自动改发明文 `PING`，不会向下位机发送加密帧。

明文模式只影响传输封装，第 2、3 节的消息语法完全不变。TCP 断开重连后双方自动复位为加密模式。

## 2. 上位指令（主机 → 下位机）

### 2.1 通用规则

- 每条命令一行，字段以空格分隔，**大小写不敏感**。
- 除 `PING`、`ESTOP` 外，命令应串行发送并等待应答（建议应答超时 2s）。
- `PING`、`ESTOP` 可不等应答直接发，用于实时心跳与急停。

**成功应答**：

```
OK <命令头> [附加信息]
```

**失败应答**：

```
ERR <命令头> <错误码> <说明>
```

**错误码**：

| 错误码 | 含义 | 触发场景 |
|--------|------|----------|
| `E_SYNTAX` | 语法错误 / 参数缺失 / 未知子命令或参数名 | 参数个数不对、未知 KEY、未知操作 |
| `E_RANGE` | 数值超范围 / 当前状态不允许 | 数值越界、选中对侧时启动、未设距离就推出 |
| `E_AXIS` | 未知电机轴名 | `MOTOR <axis>` 的 axis 不在支持列表中 |

### 2.8 PEDAL — 踏板控制

#### 2.8.1 PEDAL SELECT — 选中侧切换

```
PEDAL SELECT <A|B|NONE>
```

| 参数 | 说明 |
|------|------|
| `A` / `B` | ；选中后下位机只读选中侧站号 + 公用站号 1，未选中侧传感器字段（倾角/激光/推杆位置）统一上报 `nan`（`ang_cor_*` 为 0） |
| `NONE` | 两侧均读真实值 |

**副作用**：切换前若当前侧正在运行，先停止该侧推杆 + 复位该侧自动流程（发出 `DEBUG LEVEL <原侧> ABORT SELECT_CHANGED`）。

**应答**：`OK PEDAL`

上位机                          下位机
  │                               │
  │ PEDAL A START                 │
  │ ─────────────────────────────▶│ A侧开始自动调平
  │ ◀── OK PEDAL A START          │
  │                               │ (A侧运行中...)
  │ PEDAL SELECT B                │
  │ ─────────────────────────────▶│ ① 停止A侧推杆
  │                               │ ② 复位A侧自动流程
  │ ◀── OK PEDAL                  │ ③ 切换到B侧
  │ ◀── DEBUG LEVEL A ABORT SELECT_CHANGED │ (通知A侧流程中止)
  │                               │
  │ PEDAL B START                 │
  │ ─────────────────────────────▶│ B侧开始自动调平
  │ ◀── OK PEDAL B START          │
















**错误**：
- `ERR PEDAL E_SYNTAX 缺少 A/B/NONE`
- `ERR PEDAL E_SYNTAX 仅支持 A/B/NONE`

#### 2.8.2 PEDAL START / STOP — 启停单侧测试

```
PEDAL <A|B> START
PEDAL <A|B> STOP
```

**`START` 副作用**：
- 启动该侧自动测试流程（实时补正调平反光板）
- 状态机进入 `AF_LEVELING`
- 互斥检查：选中对侧时拒绝

**`STOP` 副作用**：
- 停该侧推杆电机
- 复位该侧自动流程（发出 `DEBUG LEVEL <side> ABORT PEDAL_STOP`）
- 两侧都停后设备状态回 `IDLE`

**应答**：`OK PEDAL A START` / `OK PEDAL A STOP`（含侧别）

**错误**：
- `ERR PEDAL E_RANGE 当前选中 A 侧，无法启动 B`（及反向）
- `ERR PEDAL E_SYNTAX`（参数缺失）

#### 2.8.3 PEDAL SETLOAD — 加载力设置{不使用预留指令}

```
PEDAL <A|B> SETLOAD <力值N>
```

| 参数 | 类型 | 范围 |
|------|------|------|
| 力值 | float | 0–500 N |

**应答**：`OK PEDAL`

**错误**：`ERR PEDAL E_RANGE 力值 0-500N`

#### 2.8.4 PEDAL LEVEL — 手动单次调平

```
PEDAL <A|B> LEVEL
```

**副作用**：
- 启动该侧手动单次闭环调平（用本侧倾角仪反馈，驱动本侧 MSH 角度校正电机）
- A 侧：倾角仪站号 2 → MSH 站号 10
- B 侧：倾角仪站号 3 → MSH 站号 11
- 完成后发 `DEBUG LEVEL <side> DONE comp=<deg>`

**应答**：`OK PEDAL A LEVEL`（含侧别）

**错误**：
- `ERR PEDAL E_RANGE 测试流程进行中，实时补正已启用` — 自动流程运行时拒绝手动调平
- `ERR PEDAL E_RANGE 当前选中 B 侧，无法补偿 A`（及反向）

#### 2.8.5 PEDAL PUSH — 推杆控制

```
PEDAL <A|B> PUSH START
PEDAL <A|B> PUSH STOP
```

**`PUSH START` 副作用**（按顺序执行）：
. 回零完成（或原本已回完原点）后：按该侧 `PUSH_DIST` 计算脉冲数（`PUSH_DIST × PUSH_PULSES_PER_MM`，默认 320 脉冲/mm）启动相对定位推出（站号：A=10，B=11，UART1 Modbus RTU）
- 固件侧"已离开原点"记录：推出（PUSH START 启动成功）/手动 `MOTOR PUSH MOVE`/`MOTOR PUSH STOP` 中断后置位（强制下次先回零，防止累计行程）；手动 `MOTOR PUSH HOME` 后清除（此时仍以状态字 Bit1 为准：回零未完成时 PUSH START 会再次发回零指令）
- 自动流程进行中 → 回零+推出后进入推出监测阶段（倾角稳定 3s 后发 `DEBUG PEDAL <side> STABLE`）；推出期间实时补正持续
- 纯手动（流程未启动）同样先检查状态字：已回完原点直接推出，否则先回零；完成后只推出，不上报流程事件
- 回零失败：15s 内 Bit1 未置位且 Bit2 运行位从未置位（驱动器根本没动）→ `ABORT HOME_NOT_SUPPORTED`（驱动器不支持回零/无原点开关，可改用 `MOTOR PUSH_<side> MOVE -<dist>` 收回）；活动过但未完成或 Bit3 报警 → `ABORT HOME_TIMEOUT`。失败/报警时同样写 回零并复位命令寄存器
- 回零中或推出中止时发 `DEBUG PEDAL <side> PUSH_STOPPED`

**`PUSH STOP` 副作用**：停推杆（回零中也可打断）；自动流程中回到 `AF_WAIT_PUSH`（恢复实时补正）并发 `DEBUG PEDAL <side> PUSH_STOPPED`

**应答**：`OK PEDAL A PUSH START` / `OK PEDAL A PUSH STOP`（含侧别）

**错误**：
- `ERR PEDAL E_SYNTAX 缺少 START/STOP`
- `ERR PEDAL E_RANGE 该侧推杆电机未启用`
- `ERR PEDAL E_RANGE 请先设置推出距离` — `PUSH_DIST ≤ 0`
- `ERR PEDAL E_RANGE 推杆电机无响应` — 回零指令（0x0030）或直接推出（已回完原点时的脉冲启动）Modbus 通讯失败
- `ERR PEDAL E_SYNTAX 仅支持 START/STOP`

### 2.10 MOTOR — 电机手动控制

#### 2.10.1 轴名

| axis | 电机 | 总线 / 协议 | 站号 |
|------|------|-------------|------|
| `A` | A 角度校正电机 | UART2 · MSH 私有协议 | 10 |
| `B` | B 角度校正电机 | UART2 · MSH 私有协议 | 11 |
| `PUSH_A` | A 踏板推杆步进电机 | UART1 · Modbus RTU | 10 |
| `PUSH_B` | B 踏板推杆步进电机 | UART1 · Modbus RTU | 11 |
| `STEER_X` | 方向盘 X（保留） | — | — |
| `STEER_Y` | 方向盘 Y（保留） | — | — |

#### 2.10.2 全局操作

```
MOTOR STOP
MOTOR ENABLE
MOTOR DISABLE
```

| 命令 | 副作用 | 应答 |
|------|--------|------|
| `STOP` | 全轴停止 + 复位两侧自动流程（`flowAbortAll`） | `OK MOTOR` |
| `ENABLE` | 总使能（推杆 + MSH 电机） | `OK MOTOR` |
| `DISABLE` | 总释放（推杆 + MSH 电机） | `OK MOTOR` |

#### 2.10.3 单轴操作

```
MOTOR <axis> MOVE <pos> [F<feed>]
MOTOR <axis> MOVEABS <pos> [F<feed>]
MOTOR <axis> HOME
MOTOR <axis> STOP
MOTOR <axis> ZERO
```

| 操作 | 说明 |
|------|------|
| `MOVE` | 移动到目标位置；`pos` 单位依轴类型见下；`F<feed>` 可选，单位依轴类型见下 |
| `MOVEABS` | 绝对位置移动（仅 PUSH 轴支持）；`pos`=目标行程（**mm，绝对位置**）；`F<feed>` 可选，单位同 `MOVE` |
| `HOME` | 回原点（MSH → 绝对位置 0°；PUSH → 写 0x0030 驱动器回原点，同时清除固件"已离开原点"记录，回零完成后下次 `PUSH START` 不再重复回零；STEER → 复位为 0） |
| `STOP` | 停该轴（PUSH 轴停止后置位"已离开原点"记录，下次推出前会重新回零） |
| `ZERO` | 当前位置设为零点（MSH → setZero；PUSH → 写 0x002C 清除位置计数，不影响回原点状态） |

**`MOVE` 参数语义**：

| 轴类型 | `pos` 单位 | `F<feed>` 单位 | 默认 feed |
|--------|-----------|----------------|----------|
| MSH（A/B） | 目标角度（°，绝对位置） | 最大速度（°/s） | 不限速 |
| PUSH（PUSH_A/PUSH_B） | 目标行程（**mm，相对位置；负值=反向收回**，固件按脉冲当量换算脉冲） | 最大速度（RPM） | 60 |

**`MOVEABS` 参数语义**：

| 轴类型 | `pos` 单位 | `F<feed>` 单位 | 默认 feed |
|--------|-----------|----------------|----------|
| PUSH（PUSH_A/PUSH_B） | 目标行程（**mm，绝对位置**，固件按脉冲当量换算脉冲） | 最大速度（RPM） | 60 |

> `MOVEABS` 仅支持 PUSH 轴，MSH 轴使用 `MOVE` 即为绝对位置。绝对位置定位需要已回零完成（状态字 0x0007 Bit1=1）。

**副作用**：手动操作 MSH 轴（A/B）或 PUSH 轴（PUSH_A/PUSH_B）时，先复位该侧自动流程（发 `DEBUG LEVEL <side> ABORT MANUAL_OVERRIDE`，中止前确保推杆停止），避免闭环与手动抢占。PUSH 轴执行 `MOVE` 或 `MOVEABS` 后固件置位"已离开原点"记录（下次 `PUSH START` 必先回零，防止累计行程）。

**应答**：`OK MOTOR`

**错误**：
- `ERR MOTOR E_SYNTAX 参数缺失`
- `ERR MOTOR E_AXIS 未知轴名`
- `ERR MOTOR E_SYNTAX 缺少操作`
- `ERR MOTOR E_SYNTAX 缺少位置值`
- `ERR MOTOR E_SYNTAX 未知操作`

### 2.11 ESTOP — 急停

```
ESTOP
```

无参数。可不等应答直接发。

**副作用**：
- 全部电机停止（推杆急停 + MSH 停止）
- 复位两侧自动流程（`flowAbortAll`，reason=`STOPPED`）
- 模块运行标志清零
- 设备状态 → `FAULT`

**应答**：`OK ESTOP`

## 3. 下位上报（下位机 → 主机）

下位机向上位机发送的数据分三类：**应答行**（对命令的响应）、**遥测行**（周期上报）、**事件行**（异步通知）。

### 3.1 应答行

对每条命令（除 `PING`/`ESTOP` 可不等应答）回送一行：

```
OK <命令头> [附加信息]
ERR <命令头> <错误码> <说明>
```

独立应答行（非命令的应答）：

| 应答 | 触发 |
|------|------|
| `PONG` | 收到 `PING` |
| `HELLO OK <device_id> <fw_version>` | 收到 `HELLO` |
| `INFO fw=<ver> hw=<hw> uptime=<s> ssid=<ssid>` | 收到 `INFO GET` |
| `NETCFG ssid=<ssid> pass=********` | 收到 `NET GETCFG` |

---

### 3.2 TELEMETRY — 周期遥测

按 `SET REPORT <hz>` 设定的频率（默认 10Hz）周期发送，一行：

```
TELEMETRY t=<ms> tilt_x=<°> tilt_y=<°> pedal_a_tilt_x=<°> pedal_a_tilt_y=<°> pedal_b_tilt_x=<°> pedal_b_tilt_y=<°> laser_a=<mm> laser_b=<mm> pedal_a=<脉冲> pedal_b=<脉冲> ang_cor_a=<°> ang_cor_b=<°> motor_a=0 motor_b=0 steer_x=<°> steer_y=<°> steer_free=0 sensor=<OK|NG> state=<STATE> pedal_select=<NONE|A|B>
```

#### 字段定义

| 字段 | 类型 | 单位 | 含义 |
|------|------|------|------|
| `t` | uint32 | ms | 开机以来毫秒数（单调递增） |
| `tilt_x` | float | ° | 公用倾角仪 X |
| `tilt_y` | float | ° | 公用倾角仪 Y |
| `pedal_a_tilt_x` | float | ° | A 踏板倾角 X |
| `pedal_a_tilt_y` | float | ° | A 踏板倾角 Y |
| `pedal_b_tilt_x` | float | ° | B 踏板倾角 X |
| `pedal_b_tilt_y` | float | ° | B 踏板倾角 Y|
| `laser_a` | float | mm | A 激光测距 |
| `laser_b` | float | mm | B 激光测距 |
| `pedal_a` | float | 脉冲 | A 推杆当前位置 |
| `pedal_b` | float | 脉冲 | B 推杆当前位置 |
| `ang_cor_a` | float | ° | A 角度校正电机角度|
| `ang_cor_b` | float | ° | B 角度校正电机角度 |
| `motor_a` | — | — | 兼容字段，恒 0 |
| `motor_b` | — | — | 兼容字段，恒 0 |
| `steer_x` | float | ° | 方向盘 X 命令位置 |  预留
| `steer_y` | float | ° | 方向盘 Y 命令位置 |  预留
| `steer_free` | — | — | 占位字段，恒 0 |
| `sensor` | 枚举 | — | 任一传感器读取失败 = `NG`，全部成功 = `OK` |
| `state` | 枚举 | — | 设备状态：`IDLE` / `PEDAL_RUN` / `STEER_RUN` / `FAULT` |
| `pedal_select` | 枚举 | — | 当前选中侧：`NONE` / `A` / `B` |

#### 取值规则

- **传感器读取失败** → 该字段值为 `nan`（如 `laser_a=nan`）
- **未选中侧上报 `nan`**：
  - `pedal_select=A` 时 B 侧传感器字段（`pedal_b_tilt_x/y`、`laser_b`、`pedal_b`）= `nan`，`ang_cor_b` = 0
  - `pedal_select=B` 时 A 侧同理（`ang_cor_a` = 0）
  - `pedal_select=NONE` 时两侧均读真实值
- **未知字段应忽略**，不回 ERR（前向兼容）
- `TELEMETRY` 实际为一行，示例中为排版折行

---

### 3.3 DEBUG 事件行 — 异步通知

下位机在以下情况主动发出 `DEBUG` 事件行（非命令应答，上位机应订阅解析）：

#### 3.3.1 自动流程事件

| 事件 | 格式 | 触发条件 |
|------|------|----------|
| 调平完成 | `DEBUG PEDAL <A\|B> LEVELED` | 该侧倾角 Y 进入 ±0.05° 死区（自动流程 `LEVELING` 阶段） |
| 推出后稳定 | `DEBUG PEDAL <A\|B> STABLE` | 推出后倾角连续 3s 变化 ≤0.05°，推杆已停（`PUSHING` 阶段） |
| 推杆停止 | `DEBUG PEDAL <A\|B> PUSH_STOPPED` | 推杆被停止：`PUSH STOP`（含回零中打断）、回零失败、自动流程中止 |

#### 3.3.2 手动调平事件

| 事件 | 格式 | 触发条件 |
|------|------|----------|
| 手动调平完成 | `DEBUG LEVEL <A\|B> DONE comp=<deg>` | 单次 `PEDAL <side> LEVEL` 闭环完成，`comp` = 累计补偿角（度，3 位小数） |
| 手动调平中止 | `DEBUG LEVEL <A\|B> ABORT <reason>` | 单次 `PEDAL <side> LEVEL` 被中止 |

**`ABORT` 的 reason 枚举**（手动调平中止与自动流程中止共用）：

| reason | 触发场景 |
|--------|----------|
| `TILT_TIMEOUT` | 倾角仪连续读取失败|
| `MOTOR_TIMEOUT` | MSH 电机响应失败，达到步数上限 |
| `STEP_TIMEOUT` | 调平步数用尽仍未进入死区 |
| `TILT_NOT_ENABLED` | 倾角仪硬件未启用，无法闭环 |
| `HOME_TIMEOUT` | 回原点 15s 内状态字 Bit1 未置位：驱动器活动过但未完成（原点/限位开关故障），或回零中 Bit3 报警 |
| `HOME_NOT_SUPPORTED` | 回零指令后 15s 内状态字 Bit2 运行位从未置位、Bit1 未完成（驱动器未执行回零：无原点开关/不支持 0x0030） |
| `PUSH_START_FAIL` | 回零完成后启动推出失败（Modbus 无响应） |
| `PUSH_NOT_ENABLED` | 推杆电机硬件未启用 |
| `MANUAL_OVERRIDE` | 流程中手动操作该侧电机（`MOTOR A/B/PUSH_A/PUSH_B` 的 MOVE/HOME/STOP/ZERO） |
| `SELECT_CHANGED` | 流程中切换选中侧（`PEDAL SELECT`） |
| `PEDAL_STOP` | 该侧测试停止（`PEDAL <side> STOP`） |
| `STOPPED` | 全局停止（`MOTOR STOP` / `ESTOP` / 心跳超时断连 / TCP 断连） |

## 7. 故障排除指南

### 7.1 连接问题

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 无法连接 | WiFi 未就绪 | 等待 ESP32 启动完成（约 2-3 秒） |
| 连接后立即断开 | 密码错误 | 检查 WiFi 密码，默认 `88888888` |
| 频繁断连 | 心跳超时 | 检查上位机是否每 5s 发送 `PING` |
| 重连失败 | nonce 不同步 | 重连时双方必须重置 nonce |
| 明文模式无法切入 | 未实现加密入口 | 确保先发送加密的 `DEBUG PLAIN ON` |

### 7.2 踏板测试问题

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 无法启动测试 | 未选中侧或选错侧 | 先执行 `PEDAL SELECT A/B` |
| 推杆不动作 | 未设置推出距离 | 先执行 `PEDAL <A/B> SET PUSH_DIST <mm>` |
| 调平超时 | 倾角仪故障或传动比错误 | 检查倾角仪接线，调整 `LEVEL_RATIO` |
| 推杆回零失败 | 驱动器不支持回零 | 检查原点开关接线，或使用 `MOTOR PUSH MOVE -<dist>` 手动收回 |
| 传感器读数为 nan | 传感器接线故障 | 检查对应站号的接线和电源 |
| 推杆推出后未停止 | 倾角未稳定 | 检查倾角仪是否正常工作 |

### 7.3 电机控制问题

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 电机不响应 | 轴名错误 | 检查轴名是否为 `A`/`B`/`PUSH_A`/`PUSH_B` |
| MSH 电机无法移动 | 电机未使能 | 先执行 `MOTOR ENABLE` |
| 推杆移动方向反了 | 正负值设置错误 | `MOVE` 正值=推出，负值=收回 |
| 位置不准 | 未回零或脉冲当量错误 | 先执行 `MOTOR <axis> HOME`，检查 `PUSH_PULSES_PER_MM` |
| 电机移动中急停 | 手动操作触发自动流程中止 | 正常行为，需重新启动测试 |

### 7.4 网络配置问题

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 修改 SSID 后无法连接 | 新 SSID 未生效 | 需要重启 ESP32 才能生效 |
| 忘记密码 | 无法修改配置 | 使用紧急恢复密码 `XDESIN2026` 恢复默认 |
| 密码修改失败 | 旧密码错误 | 确认当前密码是否正确 |
| 配置未保存 | NVS 写入失败 | 检查 ESP32 硬件是否正常 |

## 10. 附录：常见配置场景

### 10.1 首次使用

```bash
# 1. 连接 ESP32 WiFi (默认密码 88888888)
# 2. 建立 TCP 连接
# 3. 握手
HELLO xdesin-host
# 4. 查询设备信息
INFO GET
# 5. 设置遥测频率
SET REPORT 20
# 6. 开始测试
PEDAL SELECT A
PEDAL A SET PUSH_DIST 25.0
PEDAL A START
```

### 10.2 修改 WiFi 配置

```bash
# 1. 查询当前配置
NET GETCFG
# 2. 修改配置 (需要旧密码)
NET SETCFG oldpass123 MyWiFi NewPassword123
# 3. 等待重启后重新连接
```

### 10.3 忘记密码恢复

```bash
# 使用紧急恢复密码恢复默认配置
NET RESET XDESIN2026
# 等待重启后使用默认密码连接
```

### 10.4 推杆校准

```bash
# 1. 设置脉冲当量
SET PUSH_PULSES_PER_MM 320
# 2. 设置传动比
SET LEVEL_RATIO 1.0
# 3. 测试推杆移动
MOTOR PUSH_A MOVE 10.0
# 4. 检查位置是否准确
# 5. 如果不准，调整脉冲当量
```

### 10.5 调平校准

```bash
# 1. 手动调平测试
PEDAL A LEVEL
# 2. 查看调平结果
# 3. 如果调平不准，调整传动比
SET LEVEL_RATIO 1.5
# 4. 再次测试调平
PEDAL A LEVEL
```

## 12. 安全注意事项

### 12.1 WiFi 安全

- 默认密码 `88888888` 仅用于测试环境
- 生产环境必须修改为强密码
- WiFi 配置修改需要旧密码验证
- 支持紧急恢复密码 `XDESIN2026`

### 12.2 通信安全

- 所有通信使用 AES-128-CTR 加密
- HMAC-MD5 完整性校验
- 防重放保护（nonce 递增）
- PSK 必须保密，修改后需同步更新两端

### 12.3 操作安全

- 紧急停止命令 `ESTOP` 优先级最高
- 电机操作前确保安全区域无人
- 自动流程中手动操作会中止流程
- 推杆回零依赖硬件原点开关
